# MAPSO.RADAR

رادار الحضور الرقمي لعيادات الأسنان — فحص شامل من **20 معياراً** موزعة على **5 ركائز**، مع نتيجة من 100، وخطة عمل مرتبة بالأولويات، وتقرير **PDF أنيق قابل للطباعة**.

## ما الذي يفحصه الرادار؟

| الركيزة | المعايير |
| --- | --- |
| **إنستغرام ووسائل التواصل** | حساب خاص بالعيادة، نشاط الحساب (آخر 30 يوماً)، وتيرة النشر، القصص، محتوى قبل/بعد، الشبكات الأخرى |
| **فيديو العيادة** | جولة فيديو: الخارج → الاستقبال → قاعة الانتظار → قاعة العلاج، الجودة، النشر |
| **خرائط جوجل والتقييمات** | ملف مُطالَب به، صور الخارج / الاستقبال / قاعة الانتظار / كرسي الأسنان، متوسط التقييم، عدد التقييمات |
| **الموقع الإلكتروني والحجز** | موقع نشط، حجز عبر الإنترنت، تجربة الهاتف، محتوى واضح |
| **الردود والتفاعل** | الرد على تقييمات جوجل، أسئلة المرضى، واتساب للأعمال، زمن الرد |

## التقنيات

- **Next.js 16** (App Router) + React 19 + Tailwind CSS v4
- **PostgreSQL** + Drizzle ORM
- framer-motion, lucide-react — خطوط عربية Cairo و IBM Plex Sans Arabic

## التشغيل محلياً

```bash
npm install
# أنشئ ملف .env وفيه:
# DATABASE_URL="postgresql://postgres:postgres@127.0.0.1:5432/app_db"
npx drizzle-kit push   # ينشئ جدول "audits"
npm run dev
```

> الجدول يُنشأ تلقائياً أيضاً عند بدء الخادم (ملف `src/instrumentation.ts`).

## النشر على GitHub

```bash
git init -b main
git add -A
git commit -m "MAPSO.RADAR — فحص الحضور الرقمي لعيادات الأسنان"
# أنشئ مستودعاً فارغاً على github.com ثم:
git remote add origin https://github.com/<اسمك>/mapso-radar.git
git push -u origin main
```

## النشر على Vercel

1. **قاعدة البيانات**: أنشئ Postgres بدون خادم — [Neon](https://neon.tech) (مجاني) أو Vercel Postgres، وانسخ `DATABASE_URL`.
2. في [vercel.com](https://vercel.com) ← **Add New… → Project** ← استورد المستودع من GitHub.
3. أضف متغير البيئة `DATABASE_URL` في **Environment Variables**.
4. اضغط **Deploy** — بناء Next.js يُكتشف تلقائياً، والجدول سيُنشأ عند أول تشغيل.

## تصدير PDF

افتح أي تقرير ← **طباعة / PDF** ← نافذة الطباعة تفتح على تنسيق A4 منسّق ← اختر **«حفظ بصيغة PDF»**.
